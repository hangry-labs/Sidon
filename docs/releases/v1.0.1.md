# Sidon v1.0.1

Full, tiny and corresponding-source images are published and independently
verified in both official registries.

This patch fixes authentication-related navigation and improves API-key controls
in the browser studio.

- Keep every tab accessible when the server requires an API key. Unauthorized
  background requests no longer repeatedly force System open.
- Pause unauthorized polling until Connect retries authentication; resume the
  selected job after a successful reconnect.
- Retain the entered key masked after Connect, with an eye button to show/hide it
  and a Copy button that works without revealing it. Copy supports secure browser
  contexts and plain HTTP deployments.
- Mask the key again when leaving System or hiding the page. The key stays only
  in page memory and clears on reload. The server's configured secret is never
  returned to the browser.

API authentication remains optional through `SIDON_API_KEY`. Existing server-side
protection is preserved. Audio inference, model weights and runtime dependency
pins are unchanged from v1.0.0.

Chromium checks cover keyed/key-free access, wrong-key retry, successful reconnect,
both clipboard paths and 320/390/768/1440px layouts. The studio/public API tests
and release-policy checks passed.
